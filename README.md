# PDF-Editor

对PDF文件进行标注,下载。

# Demo

[https://itzhenzichao.github.io/pdf-editor/](https://itzhenzichao.github.io/pdf-editor/)

# Features

* Create new PDFs
* Draw Text
* Draw SVG Paths
* Draw Vector Graphics
* Undo
* Embed Fonts (supports UTF-8 and UTF-16 character sets)

## Usage Examples
```
yarn install

yarn dev
```
